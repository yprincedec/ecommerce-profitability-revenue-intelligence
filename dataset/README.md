# Dataset

This project uses the Tableau Sample Superstore sample dataset.

## Download

Source: https://public.tableau.com/app/sample-data/sample_-_superstore.xls

1. Download the Excel file from the official Tableau sample-data page.
2. Keep the raw file locally or upload it directly to Google Colab.
3. Do not commit the raw dataset to this repository unless its redistribution terms and repository size have been checked.

## Expected data themes

The workbook is expected to include order dates, shipping dates, customer and product information, geography, sales, quantity, discount, and profit. Exact columns and data quality will be verified in the first notebook before analysis.

## Important limitation

This is fictional retail transaction data. It does not provide website analytics, advertising spend, marketing campaign costs, or inventory records.
